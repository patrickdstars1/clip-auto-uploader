Privacy Policy

Last updated: 10 November 2026

Clip Auto Uploader ("the app") is a personal tool operated by Patcharapon Khongmod ("I", "me"). This policy explains what information the app accesses through YouTube API Services and how it is handled.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

What the app accesses

The app requests the following scope: https://www.googleapis.com/auth/youtube.upload ("Manage your YouTube videos"). It is used only to upload videos, that I choose, to the YouTube channel of the Google account that signs in.

What the app stores

  • An OAuth refresh/access token for each signed-in account, stored only as a local file on the computer running the app.
  • The ID of each uploaded video, written to a local log file on that computer.

The app does not collect, store or process any other YouTube user data, does not send data to any server operated by me, and does not share, sell or disclose any data to third parties.

Data retention and deletion

Stored tokens and logs remain on the local computer until deleted. They can be deleted at any time by deleting the app's tokens folder and log files. No copy exists elsewhere. API data is not retained after use beyond what is described above.

Revoking access

You can revoke the app's access to your Google account at any time through the Google security settings page. After revocation, the app can no longer access your YouTube account.
